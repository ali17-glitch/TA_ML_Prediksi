# 🏙️ Smart City Poverty AutoML Prediction Console

Sistem Analisis Prediktif & Pengambilan Kebijakan Mengenai Kemiskinan Berbasis Machine Learning untuk Pemerintah Daerah & Kota Cerdas di Indonesia. Proyek ini dikembangkan sebagai Tugas Akhir / UAS Praktikum Machine Learning.

---

## 🌟 Fitur Utama

- **🛡️ Portal Keamanan Eksekutif (Login Gate):** Membatasi akses ilegal dengan antarmuka portal login *Executive Glassmorphism* yang mewah.
- **📥 AutoML Engine (Dynamic Dataset Uploader):** Mendukung pengunggahan berkas Excel (`.xlsx`) kustom dengan struktur apa saja. Sistem akan secara otomatis mendeteksi kolom prediktor, menyusun *sliders* input secara dinamis, dan melatih ulang model secara real-time.
- **🔮 Real-Time Interactive Prediction:** Menghitung prediksi tingkat kemiskinan secara instan dengan kategori status (Aman/Waspada/Gawat) dan solusi kebijakan konkret yang disarankan.
- **📈 Advanced Visualization Workspace:** Menyediakan visualisasi kontribusi fitur (*Feature Importance*) dan sebaran akurasi (*Actual vs Predicted*) yang interaktif.
- **📓 Dual-Mode Deployment:** Dapat dijalankan secara akademis (CLI Pipeline) dan dasbor interaktif (Streamlit).

---
